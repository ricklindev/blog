# Editorial circle favicon provenance

The approved artwork was supplied by the site owner on 2026-09-07. It uses a dark blue open brush circle. The warm-paper source is preserved as `editorial-circle-icon-original.png`; the transparent source is preserved as `editorial-circle-icon-transparent-original.png`.

The favicon exports use the warm-paper source so browsers render a stable background. The page header uses a separate transparent 144×144 export, displayed at 36×36, so the mark sits directly on the page without a visible square and remains sharp on high-density screens.
