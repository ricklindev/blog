# Cover assets

`work-before-automation.png` is original editorial artwork generated with the built-in image tool for this repository on 2026-09-04. It depicts a solitary figure on a stepped cliff facing a celestial disc, as a metaphor for understanding a human workflow before automating it.

The 1536×1024 PNG uses a warm paper substrate (`#F6F3EA`) and cobalt ink (`#2347B8`) with risograph, halftone, and photocopy texture. Use it decoratively as the article cover for the work-before-automation essay; HTML supplies all textual content. The same artwork is duplicated at `public/og-default.png` as the static default social image.

`leaving-room-for-slow-thinking.png` is original editorial artwork generated with the built-in image tool for this repository on 2026-09-04. It depicts a single partially unfurling fern, a metaphor for giving ideas time.

The 3:2 landscape PNG uses warm paper (`#F6F3EA`) and botanical ink (`#008A4B`) with mechanical print texture. Use it decoratively as the article cover for the slow-thinking essay; the website renders all text.
