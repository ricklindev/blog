# Design Direction

## Approved creative direction

The blog should feel like a **quiet independent editorial publication**.

The approved mix is:

- **Anthropic Newsroom** — editorial hierarchy, whitespace, visual confidence
- **achin.me** — personal simplicity, low-density structure
- **mono-color visual grammar** — one-ink print-inspired cover imagery

The result should not look like any one reference directly.

## Primary approved reference

`references/typography-reference.png`

This image currently best expresses the desired:

- restrained typography scale
- density
- whitespace
- relationship between type and cover image
- editorial rather than marketing feeling

## Approved prototypes

- `prototypes/home.html`
- `prototypes/article.html`

## Anti-goals

Do not turn the site into:

- a generic AI landing page
- a SaaS dashboard
- a developer portfolio template
- a Medium-style card grid
- a neon / terminal tech blog
